# 实验记录

每次正式评测一条。文件名：`YYYY-MM-DD-<run_id>.md`

## 必填字段

| 字段 | 说明 |
|---|---|
| run_id | 与记录文件同名 |
| 日期 | |
| commit | 代码版本 |
| 模型 | 名称 + 是否改过配置 |
| 数据集 | split（dev/report）+ subset 规格 + 条数 |
| 指标 | 分类别 + 宏平均 + 95% CI |
| 成本 | 总成本、单条成本、output token 中位数/p95 |
| 耗时 | 墙钟时间 |
| 结论 | 一句话 |
| 异常 | 失败分布、超上下文条数、可疑现象 |
