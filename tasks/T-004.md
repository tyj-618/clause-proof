## 数据准备

数据不在仓库里（`.gitignore` 已排除 `data/`）。需要先下载：

```bash
mkdir -p data/cuad
curl -L -o data/cuad/CUAD_v1.json \
  "https://huggingface.co/datasets/theatticusproject/cuad/resolve/main/CUAD_v1/CUAD_v1.json"
```

约 38MB。文件结构：`{"data": [{"title": ..., "paragraphs": [{"context": 全文, "qas": [...]}]}]}`。

每条 `qa` 的 `question` 形如 `... related to "Governing Law" ...`，用正则取引号内的类别名；
`answers[0]` 含 `text` 与 `answer_start`（无 answers 表示该条款不存在）。

```python
# src/clauseproof/locate.py

def locate(quotes: Sequence[str], text: str) -> tuple[Span, ...]:

DEFAULT_CUAD_PATH: Path          # <项目根>/data/cuad/CUAD_v1.json

def load_contracts(path: Path | None = None) -> tuple[tuple[str, str], ...]:
    """返回 ((contract_id, 全文), ...)，按 contract_id 升序，保证确定性。"""

def assign_split(contract_id: str) -> str:
    """确定性划分：sha256(contract_id) 取前 4 字节 mod 100，< 60 → "dev"，否则 "report"。"""

def build_queries(
    *, split: str, n_contracts: int, seed: int, path: Path | None = None
) -> tuple[Query, ...]: ...

def load_gold(
    *, split: str, n_contracts: int, seed: int, path: Path | None = None
) -> dict[str, GoldLabel]: ...
```

**分层抽样规则**：该 split 内的合同按全文长度升序排序，均分为短/中/长三段，各取 `ceil(n_contracts/3)` 份（最后一段保证总数恰为 `n_contracts`），每段内按 `seed` 打乱后取。同一 `(split, n_contracts, seed)` 必须产出同一集合与同一顺序。

## 验收标准

**locate**

- [ ] 输出长度等于输入，顺序一一对应
- [ ] 空字符串 quote → `valid=False`、`occurrences=0`，不抛异常
- [ ] `occurrences = text.count(quote)`；`valid` 当且仅当 `occurrences >= 1`
- [ ] `valid` 时 `start = text.find(quote)`、`end = start + len(quote)`，且 `text[start:end] == quote`
- [ ] 同一 quote 出现多次时取**首次**出现，`occurrences` 如实记录
- [ ] 纯函数：同一输入两次调用返回相等结果

**dataset**

- [ ] `load_contracts` 对同一文件两次调用返回完全相同的元组（顺序固定）
- [ ] `assign_split` 是纯函数；`"dev"` 与 `"report"` 的合同集合不相交
- [ ] `build_queries` 与 `load_gold` 的 `query_id` 集合完全一致
- [ ] 同一 `(split, n_contracts, seed)` 两次调用，`query_id` 序列完全相同（含顺序）
- [ ] 换 `seed` 会改变抽到的合同集合（避免退化）
- [ ] 每份入选合同恰好产生 6 条查询，`Contract × 6` 关系成立
- [ ] `query_id` 形如 `<contract_id>::<ClauseKey.name>`
- [ ] gold span 可回原文逐字取回；取不回时**计入异常计数并跳过该 span**，不抛异常
- [ ] `Query` 中不含任何 gold 字段

**工程**

- [ ] 单元测试用**内置的极小 CUAD 样本**（2–3 份合同，每份少量 qa），不依赖 38MB 真实文件
- [ ] 针对真实文件加一个 `@pytest.mark.slow` 测试，默认不跑（`make test` 跳过）
- [ ] `make check` 全绿
