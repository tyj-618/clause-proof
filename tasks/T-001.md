## 契约

以 `0002-data-model.md` §2–§6 为准。字段名、类型、顺序必须一致。

**枚举**（4 个）：`ClauseKey`（6 项）、`Presence`（3 项）、`Route`（2 项）、`Status`（3 项）。

**数据结构**（7 个，全部 `@dataclass(frozen=True, slots=True)`）：
`Query`、`Judgment`、`Span`、`Record`、`GoldSpan`、`GoldLabel`、`RunMeta`。

另需在 `judge.py` 中定义（仅类型，无实现）：

```python
@dataclass(frozen=True, slots=True)
class CallMeta:
    model: str
    prompt_hash: str
    input_tokens: int
    output_tokens: int
    latency_ms: float
    cached: bool


@runtime_checkable
class Judge(Protocol):
    def judge(self, query: Query) -> tuple[Judgment, CallMeta]: ...
```

## 验收标准

**不可变性**

- [ ] 对任一数据结构的实例赋值属性，抛 `FrozenInstanceError`
- [ ] 所有结构声明了 `frozen=True` 与 `slots=True`

**不变式**（每条至少一个测试，违反时抛 `ValueError`）

- [ ] `Query.query_id` 必须等于 `f"{contract_id}::{clause.name}"`
- [ ] `Query.contract_id`、`Query.contract_text` 非空
- [ ] `Query.contract_id` 不得包含 `::`
- [ ] `Judgment.confidence` 落在 [0.0, 1.0]
- [ ] `Judgment.present == ABSENT` 时 `quotes` 为空
- [ ] `Judgment.present == PRESENT` 时 `quotes` 至少一项
- [ ] `Judgment.parse_ok == False` 时 `present is UNCERTAIN` 且 `confidence == 0.0`
- [ ] `Span.valid` 为真时 `start`、`end` 非空且 `0 <= start < end`
- [ ] `Span.valid` 为假时 `start`、`end` 均为 `None`
- [ ] `Span.occurrences >= 0`；`valid` 为真时 `occurrences >= 1`
- [ ] `Record.status == OK` 时 `judgment` 与 `route` 非空
- [ ] `Record.status != OK` 时 `judgment is None`、`spans == ()`、`route is None`
- [ ] `Record` 的 `input_tokens`、`output_tokens`、`latency_ms` 均 `>= 0`
- [ ] `Record` 的 `run_id`、`model`、`commit`、`prompt_hash`、`created_at` 非空
- [ ] `GoldLabel.has_answer` 等于 `len(spans) >= 1`
- [ ] `GoldSpan` 满足 `0 <= start < end` 且 `text` 非空
- [ ] `RunMeta.seed` 落在 `[0, 2**63)`；`split` 只能是 `"dev"` 或 `"report"`

**错误信息**

- [ ] 每条 `ValueError` 的消息符合 `<模块>: <字段> 违反 <约束>，期望 <期望值>，实际 <实际值>`

**协议可注入**

- [ ] 测试中定义 `FakeJudge`，`isinstance(FakeJudge(), Judge)` 为真
- [ ] `FakeJudge` 返回固定 `Judgment`，不调用任何模型

**工程**

- [ ] `make check` 全绿
- [ ] 所有公开函数与类带类型注解
