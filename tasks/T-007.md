## 口径定义（必须严格照做）

**分母**

| 指标 | 分母 |
|---|---|
| `accuracy` | `n_decided`（OK 且 present 为 PRESENT/ABSENT） |
| `uncertain_rate` | `n_total`（全部记录，含失败） |
| `citation_valid_rate` | 该类别的全部 span 数（含 invalid） |
| `citation_iou` / `citation_contained` | 该类别的全部 gold span 数 |

**恒等关系**：`n_total == n_decided + n_uncertain + n_failed`

**判定正确性**（PRD §7.1）
- gold.has_answer 为真且 present==PRESENT → 正确
- gold.has_answer 为假且 present==ABSENT → 正确
- 其余 decided 情形 → 错误

**引用准确率**
- 只使用 `span.valid == True` 的预测区间
- `citation_iou`：对该类别每条记录的每个 gold span，取与所有有效预测区间的最大 IoU，
  再对全部 gold span 求平均（未命中记 0）
- `citation_contained`：预测区间完全落在某个 gold span 内则记 1，否则 0，同样对 gold span 平均
- `iou_threshold` 只用于 `citation_contained` 之外的诊断口径；本期不参与主指标计算，
  保留在 Report 中以便后续使用

**bootstrap 置信区间**
- 对 `n_decided` 条判定做有放回重采样，1000 次，取 2.5% 与 97.5% 分位
- 随机源必须由 `seed` 派生（同一 seed 两次运行结果完全相同）
- `n_decided == 0` 时返回 None

**校准**
- 等频分桶：按 confidence 升序排序后等分；最后一桶可略多
- 桶内样本数 < `min_bin_size` 时与相邻桶合并（优先并入前一个桶）
- `mean_confidence` 为桶内 confidence 均值；`accuracy` 为桶内布尔真值比例
- `expected_calibration_error` = Σ(nᵢ/N)·|accᵢ − confᵢ|；空桶或 N==0 返回 None
- `ClauseMetrics.ece` 的输入 pairs 为该类别 `n_decided` 条记录的 (confidence, 是否正确)

**分位数**
- `p95_latency_ms` 使用 nearest-rank 法：排序后取索引 `ceil(0.95*n)-1`

## 验收标准

**基本契约**

- [ ] `by_clause` 恰好 6 项，顺序与 `ClauseKey` 定义一致
- [ ] 同一输入 + 同一 seed 两次调用，返回对象逐字段相等
- [ ] 不同 seed 只影响 `accuracy_ci`，不影响其余字段
- [ ] `macro_accuracy` = 各类 `accuracy` 的算术平均，`None` 的类别跳过；全为 None 时为 None

**分母与恒等**

- [ ] `n_total == n_decided + n_uncertain + n_failed`（对每个类别与全局都成立）
- [ ] 失败记录计入 `n_total` 与 `n_failed`，不计入 `n_decided` / `n_uncertain`
- [ ] `uncertain_rate` 的分母是 `n_total`

**判定正确性**

- [ ] 四种组合（gold 有/无 × present 有/无）判定正确
- [ ] `present == UNCERTAIN` 不计入 `n_decided`，也不计入 `n_correct`

**引用指标**

- [ ] `iou()` 覆盖：完全重叠=1、无重叠=0、包含关系、边界相接=0、零长度区间返回 0
- [ ] 只用有效 span 参与 IoU 计算
- [ ] 无 gold span 的类别，`citation_iou` 与 `citation_contained` 为 None
- [ ] 无任何 span 的类别，`citation_valid_rate` 为 None

**校准**

- [ ] 完美校准的数据 ECE ≈ 0
- [ ] 全对但 confidence 全 0.5 的数据，ECE ≈ 0.5
- [ ] 小桶会被合并；合并后桶数与 min_bin_size 的关系符合预期
- [ ] 空输入返回空元组，ECE 返回 None
- [ ] pairs 中 confidence 越界（<0 或 >1）抛 ValueError

**数据异常**

- [ ] `records` 中出现重复 `query_id` 时抛 ValueError，消息含该 id 与出现次数
- [ ] `records` 中某个 `query_id` 不在 `gold` 中时抛 ValueError，消息含该 id
- [ ] `gold` 中有条目在 `records` 中缺失时不报错（允许只评测子集）

**汇总字段**

- [ ] `total_cost_cny` 等于全部记录的 `cost` 之和（失败记录按 0 计）
- [ ] `mean_input_tokens` / `mean_output_tokens` 的分母是 `n_ok`
- [ ] `p95_latency_ms` 按 nearest-rank 计算

**工程**

- [ ] 全部测试用合成记录，不读真实文件、不调模型
- [ ] `make check` 全绿
