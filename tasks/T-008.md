## 目标

实现路由阈值的自动选择，以及「人工复核率 – 准确率」曲线的扫描。
这是项目对外主张「不硬答」的落点：给定人工预算，模型知道该把哪些交出去。

## 前置约定

`select_thresholds` 需要判断「哪些条目自动通过后仍然正确」，因此**必须拿到 gold**。

## 契约

```python
# src/clauseproof/route.py

@dataclass(frozen=True, slots=True)
class RoutingPoint:
    target_review_rate: float
    actual_review_rate: float
    auto_pass_accuracy: float | None    # 自动通过条目中判对的比例
    post_review_accuracy: float         # 1 − 自动通过且错误数 / 全部条目数
    thresholds: dict[ClauseKey, float]

def select_thresholds(
    records: Sequence[Record],
    gold: Mapping[str, GoldLabel],
    *,
    target_review_rate: float,
) -> dict[ClauseKey, float]

def sweep(
    records: Sequence[Record],
    gold: Mapping[str, GoldLabel],
    *,
    review_rates: Sequence[float],
) -> tuple[RoutingPoint, ...]
```

## 算法要求

**候选阈值**：每个条款类别的候选集 = 该类别中实际出现过的 confidence 值（去重升序）∪ {0.0}。

**目标**：在整体转人工率 ≤ `target_review_rate` 的前提下，最大化自动通过条目的准确率。

**确定性贪心**（可自行实现细节，但必须满足）：
1. 初始所有类别阈值 = 0.0（尽可能自动）
2. 若整体复核率 > 目标，则每次挑选「提升一档阈值后，减少错误数 / 增加的复核数」最大的类别，提升一档
3. 并列时按 `ClauseKey` 定义顺序取第一个
4. 无可提升时停止

**路由规则**沿用 `apply_route`：`UNCERTAIN` 恒转人工，其余按阈值。

**复核率的定义**：`转人工条数 / 全部记录数`，分母含失败记录（失败记录必然转人工）。

## 验收标准

**select_thresholds**

- [ ] 返回恰好 6 个键，值为候选集中的元素
- [ ] 用返回的阈值重算，实际复核率 ≤ `target_review_rate + 1e-9`
- [ ] 同一输入两次调用返回完全相同的字典（确定性）
- [ ] `target_review_rate < 不可约复核率`（即 UNCERTAIN + 失败记录的占比）时抛 ValueError，
      消息含目标值与实际下界
- [ ] `target_review_rate == 1.0` 时所有阈值取最大值（全部转人工），复核率为 1
- [ ] 阈值越高，复核率单调不减（对同一记录集）

**sweep**

- [ ] 返回长度等于 `review_rates`
- [ ] 每个点的 `actual_review_rate` 满足对应目标的约束
- [ ] `review_rates` 升序时，`actual_review_rate` 单调不减
- [ ] `post_review_accuracy` = 1 − 自动通过且错误数 / 全部记录数
- [ ] 无自动通过条目时，`auto_pass_accuracy` 为 None
